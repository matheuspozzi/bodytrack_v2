BODYTRACK — NOVA VERSÃO 1.0

PUBLICAÇÃO
1. Extraia o ZIP.
2. Envie o conteúdo de bodytrack_novo para a raiz do repositório GitHub (index.html, manifest.webmanifest, sw.js, README.txt e icons/).
3. Mantenha GitHub Pages em main / root.
4. Aguarde a publicação e abra pelo endereço HTTPS.

RECURSOS IMPLEMENTADOS
- PWA instalável e cache offline.
- IndexedDB local.
- Perfis independentes no mesmo dispositivo.
- Dashboard com indicadores e gráfico de peso.
- Peso, IMC, medidas, composição corporal e fotos comprimidas.
- Nutrição com base inicial de alimentos e cadastro manual.
- Refeições, água e suplementação.
- Fichas, sessão de treino, séries, cargas, descanso e recordes.
- Calendário, CSV, relatório imprimível em PDF.
- Backup JSON por perfil, incluindo fotos; restauração com opção de substituir ou mesclar.
- Tema claro/escuro e cor de destaque.
- Tentativa de migração do localStorage bodytrack-data-v1; dados antigos não são apagados.

IMPORTANTE
- A base alimentar incluída é inicial e aproximada. Confira rótulos e fontes confiáveis.
- Sugestões de metas são estimativas e não substituem orientação profissional.
- Perfis são separados logicamente, sem PIN ou criptografia.
- Não há sincronização em nuvem. Faça backups regulares e guarde-os fora do dispositivo.
- A versão antiga pode exigir importação manual caso o formato do backup seja diferente.
